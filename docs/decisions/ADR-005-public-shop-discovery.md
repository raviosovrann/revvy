# ADR-005: Public Shop Discovery

**Status:** Accepted
**Date:** 2026-07-18

## Context

V1 must decide whether customers find shops via deep links/QR codes only, or also via basic search.

## Decision

The first pilot supports shop discovery through verified **QR codes and deep links only**. Public marketplace search is deferred until pilot evidence justifies verification, spam controls, ranking, and privacy work.

## Consequences

- Simpler implementation; no ranking, reviews, or marketplace logic
- Shop owners must share their link or QR code directly
- Limits organic discovery but reduces spam and privacy concerns
